# img2prompt 需求文档（PRD）

## 1. 背景与目标
AI 绘画（Midjourney / Stable Diffusion / FLUX）需要高质量的英文提示词，但普通用户看到一张喜欢的图片时，很难把它"翻译"成有效的提示词。img2prompt 的目标是：**在浏览网页时，对任意图片一键生成可直接使用的 AI 绘画提示词**，流程短到只有一次右键。

## 2. 目标用户
- AI 绘画爱好者、设计师、自媒体配图需求者
- 有 API 调用能力（自备 Key）的用户，首版不做账号系统

## 3. 核心场景
1. 用户在网页上看到一张喜欢的图片 → 右键 →「生成图片提示词」→ 页内悬浮面板展示中文提示词 → 一键复制
2. 需要英文版 → 面板内点 EN → 重新生成英文
3. 只想要图片局部 → 快捷键 `Ctrl+Shift+Y` 框选 → 识别选中区域
4. 电脑里的本地图片 → 点工具栏图标 → popup 拖放上传 → 生成

## 4. 功能需求

### P0（已实现，v0.1.0）
- 右键图片生成提示词，中英一键切换
- 页内悬浮面板（Shadow DOM 样式隔离），一键复制
- BYOK：任意 OpenAI-compatible 视觉接口
- 设置页：API Key / Base URL / 模型 / 默认语言 / 连接测试
- 本地历史（最近 20 条），popup 查看 / 复制 / 清空

### P1（已实现，v0.2.0 开发中）
- 多服务商配置管理（新增 / 切换 / 测试连接）
- 提示词模板：内置通用 / 摄影 / 插画 / JSON 结构化 + 自定义增删改
- 框选截图识别 + 快捷键 `Ctrl+Shift+Y`
- popup 拖放 / 上传本地图片
- 历史搜索 / 收藏
- 请求取消、结构化 JSON 输出渲染

### P2（候选，v0.3.0）
- Chrome Web Store 上架
- 侧边栏历史（替代 popup 列表）
- 批量识别

## 5. 非功能需求
- 生成链路端到端可验证：单元测试 + 真机 E2E（真实 Chromium + 真实 API）
- 质量门禁：typecheck / eslint / prettier / 单测 / 构建，全部通过才可合并
- 隐私：API Key 与所有数据只存浏览器本地；图片只发往用户自己配置的接口
- UI：中英双语，遵循系统原生设计语言（Apple HIG 风格），禁用紫兰配色

## 6. 非目标（明确不做）
- 不做服务端、不做账号系统、不做提示词云端同步
- 不做图片生成（只做提示词）
- 首版不做 Firefox / Safari 移植
