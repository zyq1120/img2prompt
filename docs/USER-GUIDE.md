# img2prompt 用户手册

## 安装
1. 下载 [Releases](https://github.com/zyq1120/img2prompt/releases) 页的 `img2prompt-v*.zip` 并解压
2. 打开 `chrome://extensions`，开启右上角"开发者模式"
3. 点击"加载已解压的扩展程序"，选择解压后的文件夹

## 配置 API（只需一次）
1. 右键工具栏图标 →「选项」，或在 popup 中点设置
2. 在"API 配置"中填写：
   - **Base URL**：如 `https://api.openai.com/v1`（OpenAI 官方）
     第三方中转填服务商给的地址；本地模型如 Ollama 填 `http://localhost:11434/v1`
   - **API Key**：你的密钥（只保存在本机，不上传）
   - **模型**：如 `gpt-4o-mini`（需是支持图片输入的视觉模型）
3. 点"测试连接"，看到成功提示即可
4. 可添加多个服务商配置并随时切换

## 使用方法
- **右键图片** →「生成图片提示词」→ 页内右下角悬浮面板展示结果 → 点 Copy 复制
- **中英切换**：面板顶部点 中 / EN，复用已下载图片重新生成
- **框选识别**：在页面右键 →「框选截图并识别」，或按 `Ctrl+Shift+Y`（Mac 上 `⌘+Shift+Y`），拖拽选中区域
- **本地图片**：点工具栏图标 → 把图片拖进 popup 即可识别
- **模板**：面板内下拉可切换提示词模板（通用 / 摄影 / 插画 / JSON 结构化）；自定义模板在设置页管理
- **历史**：点工具栏图标查看最近 20 条，可搜索、收藏、复制、一键清空

## 修改快捷键
打开 `chrome://extensions/shortcuts`，找到 img2prompt 的"框选截图并识别"，点笔图标修改。

## 常见问题
- **提示"网络请求失败"**：检查 Base URL 是否正确、网络能否连通该接口
- **提示 API Key 无效（401）**：Key 填错或过期，到服务商后台重新生成
- **JSON 模板偶发报错**：模型偶发返回非 JSON，重试一次即可
- **面板没出现**：确认扩展已启用；部分 chrome:// 系统页面扩展无法注入
- **隐私**：API Key、历史、配置全部只存你的浏览器本地；图片只在生成时发往你自己配置的接口
