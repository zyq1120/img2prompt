img2prompt — 右键图片，一键生成 AI 绘画提示词

## 简短介绍（132 字以内）
在任意网页图片上右键，一键生成适用于 Midjourney / Stable Diffusion / FLUX 的 AI 绘画提示词。支持中英一键切换、快捷键框选截图识别、自定义提示词模板、结构化 JSON 输出、本地历史记录。兼容任何 OpenAI-compatible 视觉接口，API Key 只保存在本地。

## 详细介绍（中文）

**img2prompt** 让每一张网页图片都变成可用的 AI 绘画提示词。

### 核心功能
- 🖱️ **右键即分析**：在图片上右键 →「生成图片提示词」，页内悬浮面板直接展示结果
- ⌨️ **快捷键框选**：`Ctrl+Shift+Y`（Mac 上 `⌘+Shift+Y`）直接进入框选截图识别，可在 `chrome://extensions/shortcuts` 自定义
- 🌐 **中英一键切换**：面板内 中 / EN 切换，复用已下载图片重新生成
- 📝 **提示词模板**：内置通用 / 摄影 / 插画 / JSON 结构化等模板，支持自定义增删改
- 🕘 **本地历史**：最近 20 条生成记录保存在本地，可搜索、收藏、复制、一键清空
- 🖼️ **多种输入**：右键图片、框选截图、popup 拖放 / 上传本地图片
- 🔑 **BYOK**：支持任何 OpenAI-compatible 视觉接口（OpenAI / 第三方中转 / 本地模型），多服务商配置管理

### 隐私承诺
- API Key 与全部数据只保存在你的浏览器本地，不上传到任何服务器
- 扩展仅在生成时把图片发送到**你自己配置的** AI 接口
- 开源，代码可审计

## 详细介绍（English）

**img2prompt** turns any web image into a ready-to-use AI art prompt.

### Features
- 🖱️ **Right-click to analyze**: context menu on any image, floating in-page panel shows the result
- ⌨️ **Shortcut for region select**: `Ctrl+Shift+Y` (`⌘+Shift+Y` on Mac) starts region capture; remappable at `chrome://extensions/shortcuts`
- 🌐 **One-click zh/en switch**: re-generates in the other language reusing the downloaded image
- 📝 **Prompt templates**: built-in general / photography / illustration / structured JSON templates, plus your own custom templates
- 🕘 **Local history**: last 20 generations stored locally — search, favorite, copy, one-click clear
- 🖼️ **Multiple inputs**: right-click image, region screenshot, drag & drop / upload in popup
- 🔑 **BYOK**: works with any OpenAI-compatible vision endpoint, multiple provider profiles

### Privacy
- API keys and all data stay in your browser's local storage — nothing is uploaded anywhere
- Images are sent only to **the AI endpoint you configured**, at generation time
- Open source, auditable code
